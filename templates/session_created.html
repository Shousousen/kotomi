セッション作成完了 🎉

以下のリンクから音声再生ページにアクセスできます：

{{ request.host }}/session/{{ session_id }}/player

音声再生用エンドポイント：

🎤 テスト音声を再生してみる（プレイヤー側で再生されます）

APIエンドポイントの利用方法：

利用可能なスタイルを取得するには：

GET {{ request.host }}/api/session/{{ session_id }}/styles

例: curlコマンド

curl -X GET {{ request.host }}/api/session/{{ session_id }}/styles

音声合成の利用方法：

音声を合成するには：

POST {{ request.host }}/api/session/{{ session_id }}/synthesize

リクエストボディの例:

{
  "text": "こんにちは",
  "style": "default"
}

例: curlコマンド

curl -X POST {{ request.host }}/api/session/{{ session_id }}/synthesize \
-H "Content-Type: application/json" \
-d '{"text": "こんにちは", "style": "default"}'

🎵 再生中断と新しい音声の再生

再生中断と新しい音声再生の利用方法：

再生中の音声を中断して新しい音声を再生するには：

POST {{ request.host }}/session/{{ session_id }}/interrupt

リクエストボディの例:

{
  "text": "新しい音声を再生します",
  "style": "default"
}

例: curlコマンド

curl -X POST {{ request.host }}/session/{{ session_id }}/interrupt \
-H "Content-Type: application/json" \
-d '{"text": "新しい音声を再生します", "style": "default"}'

使い方

再生中の音声を中断して新しい音声を再生するには、上記の入力欄にテキストを入力し、「再生を中断して再生」ボタンをクリックしてください。
