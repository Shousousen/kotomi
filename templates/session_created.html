セッション作成完了 🎉

以下のリンクから音声再生ページにアクセスできます：

{{ request.host }}/session/{{ session_id }}/player

音声再生用エンドポイント：

🎤 テスト音声を再生してみる（プレイヤー側で再生されます）

APIエンドポイントの利用方法：

利用可能なスタイルを取得するには：

GET {{ request.host }}/api/session/{{ session_id }}/styles

例: curlコマンド

curl -X GET {{ request.host }}/api/session/{{ session_id }}/styles

音声合成の利用方法：

音声を合成するには：

POST {{ request.host }}/api/session/{{ session_id }}/synthesize

リクエストボディの例:

{
  "text": "こんにちは",
  "style": "default"
}

例: curlコマンド

curl -X POST {{ request.host }}/api/session/{{ session_id }}/synthesize \
-H "Content-Type: application/json" \
-d '{"text": "こんにちは", "style": "default"}'
